Advanced Shadow Techniques

Combine shadows with transforms for sophisticated effects

Inset Shadow

Creates an inset shadow that makes elements appear pressed or recessed.

box-shadow: inset 0 2px 8px rgba(0, 0, 0, 0.2);

  • Creates depth inward
  • Perfect for input fields
  • Forms visual containment

Glow Shadow

Multiple layered shadows create a glowing effect around elements.

box-shadow: 0 0 20px rgba(102, 126, 234, 0.6), 0 0 40px rgba(102, 126, 234, 0.3);

  • Creates glowing halos
  • Draws attention to elements
  • Works with colors

Colored Shadow

Using colors in shadows creates dynamic and artistic effects.

box-shadow: 10px 10px 20px rgba(255, 107, 107, 0.3);

  • Adds color to depth
  • Creates mood
  • Enhances visual interest

Shadow Syntax Reference

Quick reference for box-shadow and text-shadow properties

Box-Shadow Syntax

Basic Syntax:

box-shadow: offset-x offset-y blur-radius spread-radius color;

Multiple Shadows:

box-shadow: shadow1, shadow2, shadow3;

Inset Shadow:

box-shadow: inset offset-x offset-y blur-radius color;

Text-Shadow Syntax

Basic Syntax:

text-shadow: offset-x offset-y blur-radius color;

Multiple Shadows:

text-shadow: shadow1, shadow2, shadow3;

Example with Blur:

text-shadow: 2px 2px 4px rgba(0, 0, 0, 0.3);

Parameters Guide

Offset-X: Horizontal distance (negative = left)

Offset-Y: Vertical distance (negative = up)

Blur-Radius: Blur amount (0 = sharp, higher = softer)

Spread-Radius: Shadow size (box-shadow only)

Color: rgba or hex color value

Pro Tips

  • Use subtle shadows for a modern look
  • Layer multiple shadows for depth
  • Keep blur-radius less than spread for sharp edges
  • Use rgba() for better color blending
  • Test on different backgrounds
