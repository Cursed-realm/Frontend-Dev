Understanding Content, Padding, Border, and Margin

Default Box Model (content-box)

Content Area

Default Behavior

With box-sizing: content-box, the width and height properties apply only to the content area. Padding and border are added on top.

Optimized Box Model (border-box)

Content Area

Border-Box Sizing

With box-sizing: border-box, the width and height include content, padding, and border. This is more predictable for layouts.

Box Model Layers Breakdown

Margin
Border
Padding
Content

Content Area

The innermost area where text, images, and other elements are displayed. Dimensions are set by width and height properties.

width: 200px; height: 100px;

Padding

Space between content and border. Creates internal spacing and separates content from the border. Padding extends the background color.

padding: 20px;

Border

A line drawn around padding and content. Can have different styles (solid, dashed, dotted) and colors. Adds visual definition.

border: 3px solid #667eea;

Margin

Space outside the border. Creates spacing between this element and other elements. Does not affect background color.

margin: 30px;

Padding vs Margin

Margin Outside

Padding is inside the border and adds to the background color. Margin is outside the border and creates space between elements without affecting background.

Auto Margins

Centered with margin: auto;

Using margin: auto with a fixed width centers the element horizontally. This is a common technique for centering blocks without Flexbox.

Box Model Reference

Content

  • Set with: width, height
  • Contains text and images
  • Background color covers content + padding

Padding

  • Set with: padding property
  • Creates internal space
  • Individual sides: padding-top, padding-right, etc.
  • Shorthand: padding: top right bottom left

Border

  • Set with: border property
  • Syntax: border: width style color
  • Styles: solid, dashed, dotted, double, groove
  • Example: border: 2px solid #667eea;

Margin

  • Set with: margin property
  • Creates external space
  • Can be negative for overlap
  • Can be auto for centering
