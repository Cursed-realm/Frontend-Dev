1. Basic Sizing Units

Explore different measurement units: px, %, em, and viewport units

Pixels (px)

Width: 200px

Height: 150px

Fixed absolute size. Doesn't scale with parent or viewport.

Percentage (%)

Width: 80%

Height: 60%

Relative to parent element's size. Responsive and flexible.

Em Units (em)

Width: 15em

Height: 10em

Relative to the font-size of the element. Scalable typography.

Viewport Height (vh)

Width: 100%

Height: 30vh

1vh = 1% of viewport height. Great for full-screen layouts.

2. Min and Max Properties

Control minimum and maximum dimensions for responsive design

Min-Height Example

min-height: 200px

height: auto

Box will never shrink below 200px, but can expand with content.

Extra content will cause the box to expand beyond minimum height.

Max-Width Example

max-width: 250px

width: 100%

Box scales down on smaller screens but won't exceed 250px on larger screens.

Min & Max Combined

min-width: 150px

max-width: 300px

Box maintains a range. Perfect for responsive flexible layouts.

Max-Height Example

max-height: 180px

Box is constrained to maximum height. Content overflow is hidden.

This is additional content that will be hidden due to max-height overflow constraints.
