Mastering Linear and Radial Gradients in CSS

Linear Gradient - Basic

This section demonstrates a basic linear gradient flowing from top-left to bottom-right.

Gradient Properties:

  • Direction: 135deg (diagonal top-left to bottom-right)
  • Color 1: #667eea (Purple-blue)
  • Color 2: #764ba2 (Deep purple)
  • Color 3: #f093fb (Pink)

Linear gradients are perfect for creating smooth color transitions in a specific direction. You can control the angle (in degrees) or use keywords like 'to right', 'to bottom', etc.

Linear Gradient - Vertical Multi-Color

This section shows a vertical linear gradient with multiple color stops.

Gradient Properties:

  • Direction: to bottom (90deg)
  • Color Stops: 4 colors with specific percentages
  • Color 1: #FF6B6B (Red) at 0%
  • Color 2: #4ECDC4 (Cyan) at 33%
  • Color 3: #FFE66D (Yellow) at 66%
  • Color 4: #95E1D3 (Mint) at 100%

By adding multiple color stops with percentage values, you can create complex and vibrant gradient effects.

Linear Gradient - Parallax Effect

This section uses background-attachment: fixed to create a parallax-like effect.

Parallax Properties:

  • Background-Attachment: fixed
  • Effect: Background stays fixed while content scrolls
  • Gradient: 45deg angle from #1e3c72 to #2a5298
  • Use Case: Creates depth and visual interest when scrolling

Scroll up and down to see the parallax effect! The background remains fixed while the content moves, creating an engaging visual experience.

Radial Gradient - Circle

This section demonstrates a radial gradient with a circular shape emanating from the center.

Gradient Properties:

  • Shape: circle
  • Position: center (50% 50%)
  • Color 1: #FFD89B (Light orange) at center
  • Color 2: #FF6B9D (Pink) at edges
  • Spread: Expands outward from center point

Radial gradients are ideal for creating spotlight effects, glowing orbs, or circular color transitions from a central point outward.

Radial Gradient - Ellipse

This section shows a radial gradient with ellipse shape creating an elongated effect.

Gradient Properties:

  • Shape: ellipse
  • Size: farthest-corner
  • Position: 30% 60%
  • Color 1: #C1FF72 (Lime) at center
  • Color 2: #00B4DB (Cyan) at edges
  • Effect: Off-center radial gradient

Ellipse gradients can be positioned off-center and use different size keywords (closest-side, farthest-side, etc.) for creative effects.

Radial Gradient - Multiple Color Stops

This section demonstrates a radial gradient with multiple color stops creating concentric circles.

Gradient Properties:

  • Shape: circle
  • Position: center
  • Color Stops: 5 distinct color rings
  • Colors: #FF0080, #7928CA, #4C3EFF, #1E90FF, #00D4FF
  • Percentages: 0%, 20%, 40%, 60%, 100%

Multiple color stops in radial gradients create beautiful concentric patterns, perfect for badges, buttons, and decorative elements.

Quick Reference Guide

Linear Gradient Syntax

background: linear-gradient(angle, color1, color2);

Example: linear-gradient(45deg, #667eea, #764ba2)

Radial Gradient Syntax

background: radial-gradient(shape position, color1, color2);

Example: radial-gradient(circle at center, #FFD89B, #FF6B9D)

Linear Gradient with Stops

linear-gradient(to right, red 0%, yellow 50%, green 100%)

Control color transitions with percentages

Radial Gradient with Stops

radial-gradient(circle, red 0%, yellow 50%, blue 100%)

Create concentric color rings

Parallax Effect

background-attachment: fixed;

Keeps background fixed while content scrolls

Direction Keywords

to top | to bottom | to right | to left

Or use degrees: 0deg, 45deg, 90deg, 180deg, etc.
