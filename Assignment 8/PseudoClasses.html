Pseudo-Classes Demonstration

:hover Pseudo-class

Hover over me!

The :hover pseudo-class is triggered when a user hovers their cursor over an element. In this example, the link changes its background and text color on hover.

:focus Pseudo-class

The :focus pseudo-class is activated when an element receives focus (usually by clicking or tabbing to it). This input field changes its border color and adds a shadow when focused.

:active Pseudo-class

The :active pseudo-class is triggered when an element is being activated by the user (e.g., clicked). This button darkens and scales down while being clicked.

The :nth-child() pseudo-class selects elements based on their position. In this list, every even-numbered item (2nd, 4th) has a different background color.
