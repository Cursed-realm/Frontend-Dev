🛍️ E-Commerce Product Highlight

Interactive product showcase with dynamic highlighting and selection

✨ Product Highlight Features

1️⃣ Click Product to Highlight

  • Click any product card to highlight it with a golden background and border
  • Only one product is highlighted at a time
  • Visual feedback with smooth transitions

2️⃣ Hover to Show Details

  • Hover over a product card to reveal additional details
  • Details appear with a smooth animation
  • Includes product description in a styled box

3️⃣ Favorite Icon Toggle

  • Click the heart icon (♡) to add/remove from favorites
  • Toggles the selected class on the product card
  • Heart changes color when favorited (♥)
  • Pink border indicates selected/favorited product

4️⃣ Discount Attribute Styling

  • Products with discounts are styled with special indicators:
  • Red discount badge showing percentage off
  • Price tag emoji (🏷️) on the card
  • Red border accent on product info section
  • Uses CSS attribute selector: [data-discount]

5️⃣ Out-of-Stock Alert

  • Uses data-in-stock attribute to track inventory status
  • Out-of-stock products show "Out of Stock" badge with red background
  • Clicking "Add to Cart" on out-of-stock items shows an alert
  • In-stock products show confirmation alert
💡 Pro Tips:
  • Try clicking different products to see the highlight effect
  • Hover over products to discover more details
  • Notice how discounted items have special styling
  • Check the out-of-stock items (USB-C Cable, Bluetooth Speaker) to see the alert
  • Favorite multiple products to build your wishlist

📊 Technical Implementation

  • CSS Attribute Selectors: [data-discount] for discount styling
  • Data Attributes: data-in-stock for stock status tracking
  • Dynamic Classes: .highlighted, .selected, .hidden
  • Event Delegation: Efficient event handling on product cards
  • CSS Grid Layout: Responsive product grid
  • Smooth Transitions: CSS animations for user interactions
